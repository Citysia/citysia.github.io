Guide d'Installation pour la version officiel de minecraft

1

Télécharger le fichier d’installation

Cliquez sur le bouton Installer pour télécharger un fichier volumineux contenant :

  • ▸ Tous les mods nécessaires pour la saison de Citysia
  • ▸ Les programmes d’installation de Forge et de Java adaptés
2

Installer Java et Forge manuellement

Attention : Java et Forge ne s’installent pas automatiquement. Après avoir téléchargé le fichier :

  • 1. Ouvrez explorateur de fichiers et trouver le fichier télécharger.
  • 2. Double-cliquez sur le fichier télécharger pour l’ouvrir.
  • 3. Vous verrez plusieurs fichiers, dont un pour installer Java et un autre pour installer Forge.
  • 4. Installez Java en double-cliquant sur le fichier Java (même si vous pensez l’avoir déjà installé).
  • 5. Installez Forge en double-cliquant sur le fichier Forge pour lancer son installation.
3

Installer les mods manuellement

Une fois Java et Forge installés :

  • 1. Commencez par lancer votre minecraft en mode forge une fois puis fermer votre jeu.
  • 2. Ouvrez le dossier téléchargé contenant le sous-dossier mods.
  • 3. Sélectionnez tous les fichiers mods et copiez-les.
  • 4. Dans l’explorateur de fichiers entrez dans la barre d’adresse : %appdata%\.minecraft\mods
  • 5. Si le dossier mods n’existe pas, cela signifie que Forge ou Java n’a pas été installé correctement. Retournez à l’étape d’installation et recommencez ou à l'étape avec le lancement de jeu en mode forge.
  • 6. Collez les fichiers mods dans ce dossier.
  • 7. Puis fermez l'explorateur de fichiers.
4

Lancer Minecraft avec les mods

Ouvrez votre launcher Minecraft officiel et sélectionnez le profil Forge correspondant, lancez le jeu et Vérifiez dans le menu Mods que les mods de la saison sont bien actifs.

Guide d'Installation pour la version crack de minecraft (TLauncher)

1

Ouvrir TLauncher et créer ton modpack

Lance TLauncher. En bas à gauche, clique sur la flèche à côté de la version (ex : “Latest Release”). Choisis la version requis pour la saison. Exemple : Forge 1.20.1 Clique sur le bouton jaune "Install". Une fois installé, dans la liste des versions, sélectionne ton Forge 1.20.1 puis lance le jeu une fois. Ça permet de créer tous les dossiers nécessaires dans .minecraft.

2

Trouver ton dossier .minecraft

Ouvre explorateur de fichiers entrez dans la barre d’adresse tape %appdata%. Ouvre le dossier .minecraft. Dedans, tu verras un dossier nommé mods. S’il n’existe pas, lance une fois ton jeu avec Forge, il se créera automatiquement.

3

Ajouter les mods

Appuyez sur le bouton télécharger. Ouvre le fichier compressé et transfert tous les mods du dossier mods dans l'autre dossier mods sur ton pc.

4

Lancer ton modpack

Retourne sur TLauncher. Sélectionne ton profil Forge. Clique sur "Enter the game". Si tout est bon, tu verras dans le menu principal un bouton “Mods” — clique dessus pour vérifier qu’ils sont bien installés.

⚠️ En cas de problème :

- Vérifiez que Java et Forge ont bien été installés manuellement. (pour les officiels)

- Assurez-vous d’utiliser la bonne version de Forge.

- Vérifier la version du mod et la version requis du serveur si un mod ne fonctionne pas.

- Contactez le support en créant un ticket sur notre discord si besoin.
